# Xorazm Pedagogika Texnikumi Elektron Kutubxonasi

Python'da yozilgan oddiy konsol kutubxona tizimi.

## Bo'limlar
- Umumta'lim fanlar
- Umumkasbiy fanlar
- Maxsus fanlar
- Badiiy adabiyotlar

## Ishga tushirish
```
python Kutubxona/main.py
```

## Imkoniyatlar
- Bo'limlarni ko'rish
- Yangi kitob qo'shish
- Bo'lim bo'yicha kitoblarni ko'rish
- Kitob qidirish (nom yoki muallif bo'yicha)

Ma'lumotlar `Kutubxona/kutubxona.json` faylida saqlanadi.
